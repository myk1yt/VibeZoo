# VibeZoo 시스템 기능 설명서

본 문서는 개발자 및 일반 사용자가 **VibeZoo**의 핵심 구조와 작동 원리를 쉽게 이해하고, 다양한 보호/협업 기능들을 효과적으로 활용할 수 있도록 돕는 공식 기능 설명서입니다.

---

## 1. 개요: VibeZoo란 무엇인가?

VibeZoo는 사용자와 AI(예: Zoo Code) 간의 코딩 협업을 극대화하기 위해 설계된 **VS Code 동반자(Companion) 프로그램**입니다. AI가 코드 작성에만 집중할 수 있도록 복잡한 파일 관리, 안전장치(백업), 빌드 에러 감지 등을 배후에서 조율합니다.

### ⚙️ 코드 레벨 작동 원리
VibeZoo는 크게 **두 가지 엔진**이 맞물려 돌아가는 하이브리드 구조입니다.

1. **프론트엔드 (VS Code Extension - TypeScript)**
   - 사용자의 화면(VS Code)에서 직접 동작합니다.
   - 사이드바(VibeZoo 탭)에 UI를 그리고, 파일이 수정되거나 저장되는 이벤트를 실시간으로 감시합니다.
   - 단축키 입력, 백업 생성(YOLO), UI 미리보기 등을 로컬 환경에서 처리합니다.
2. **백엔드 (MCP Bridge - Python)**
   - 백그라운드 서버(포트 9027)로 동작하며, 실제 AI 에이전트들과 통신(SSE)하는 '다리(Bridge)' 역할을 합니다.
   - AI가 요청하면 코드를 검색하고, 분석하고, 빌드 에러를 수정하는 등 시스템 깊숙한 곳의 도구(Tools)들을 실행하여 그 결과를 AI에게 넘겨줍니다.

## 2. 핵심 무기고 (MCP 도구 설명)

AI가 VibeZoo 백엔드를 통해 사용할 수 있는 도구들입니다. 마치 요리사가 다양한 주방 도구를 꺼내 쓰듯, AI는 필요할 때 이 도구들을 호출하여 코드를 다룹니다.

* **Scout (코드 정찰병)**
  * **기능:** 프로젝트 안에서 특정 코드가 어디 있는지 샅샅이 뒤져 찾아냅니다.
  * **원리:** 단순히 글자를 찾는 것을 넘어, 함수나 변수가 어디서 호출되었는지(참조 검색) 분석합니다.
* **Reviewer (코드 검토자)**
  * **기능:** 작성된 코드의 품질을 평가하고 리뷰해줍니다. 개선할 점을 짚어줍니다.
* **Tester (자동 테스터)**
  * **기능:** 코드에 에러가 없는지 검증하기 위한 테스트 코드를 자동으로 생성하고, 얼마나 잘 테스트되었는지(커버리지) 분석합니다.
* **Deep Analyzer (심층 분석가)**
  * **기능:** 복잡한 코드들이 서로 어떻게 의존하고 얽혀있는지 지도를 그려주는(Call Graph 및 Dependencies) 아키텍처 분석가입니다.
* **Fix Loop (자동 해결사)**
  * **기능:** 코드를 실행(빌드)하다가 에러가 나면, 사람이 개입하기 전에 에러 로그를 읽고 스스로 코드를 수정하여 다시 빌드를 시도합니다.
* **Whiteboard (화이트보드)**
  * **기능:** 텍스트만으로 설명하기 힘든 아키텍처나 UI 배치를 시각적으로 그리며 소통할 수 있게 해주는 캔버스 도구입니다.

## 3. VS Code 사이드바 (VibeZoo 탭) 집중 해부

VS Code 왼쪽의 **VibeZoo 아이콘**을 클릭하면 나타나는 사이드바의 핵심 기능들입니다. 사용자의 코드를 안전하게 지키고, 작업 흐름을 끊기지 않게 돕습니다.

### 🛡️ FileGuard (보호막)
* **어떤 기능인가요?** AI가 실수로 건드리면 안 되는 중요한 설정 파일이나 코어 모듈을 변경하려 할 때, 이를 감지하고 즉시 원상복구(치유)하는 방패입니다.
* **작동 원리:** 프로젝트에 있는 `.yoloignore` 파일에 "이 파일은 건드리지 마!"라고 적어두면, VibeZoo가(FileSystemWatcher) 이 파일들을 감시합니다. 만약 파일이 변경되면, 가장 최근의 백업(Yocto)을 찾아 5초 이내에 덮어씌웁니다. (에러가 무한 반복되는 것을 막기 위한 쿨다운 시스템도 적용되어 있습니다.)
* **사용 방법:** 사이드바의 **Active Subagents** 메뉴를 보면 방패 모양 아이콘의 `FileGuard`가 있습니다. 클릭 한 번으로 보호막을 켜거나(ON) 끌(OFF) 수 있습니다.

### 👁️ CIM Monitor (Continuous Improvement Mode)
* **어떤 기능인가요?** 사용자가 코드를 수정하고 '저장'할 때마다 자동으로 빌드와 테스트를 백그라운드에서 돌려주는 똑똑한 감시자입니다.
* **작동 원리:** 파일 변경이 감지되면 즉각적으로 컴파일(빌드) 명령을 내립니다. 여기서 실패하면 위에 설명한 **Fix Loop (자동 해결사)**를 조용히 호출하여 에러를 고치게 만듭니다.
* **사용 방법:** 명령 팔레트(`Ctrl+Shift+P`)에서 `VibeZoo: Start Watching`을 실행하거나 사이드바에서 켤 수 있습니다.

### ⏪ YOLO History (타임머신 및 즉시 복구)
* **어떤 기능인가요?** 코드를 작성하는 동안 쉴 새 없이 스냅샷(백업)을 찍어둡니다. "아차, 코드 망쳤다!" 하는 순간 클릭 한 번으로 시간을 되돌릴 수 있습니다.
* **작동 원리:** 백그라운드에서 조용히 내 컴퓨터의 `~/.zoo-code/yocto/` 폴더에 버전 기록을 남깁니다. Git을 몰라도 파일 저장 단위로 미세하게 백업이 남습니다.
* **사용 방법:** 
  1. 사이드바의 **YOLO History** 탭을 엽니다.
  2. 분 단위로 기록된 타임스탬프 중 원하는 시점을 우클릭하여 **Rewind(복구)**를 누르면 해당 시점으로 파일이 돌아갑니다.
  3. (단축키: `Ctrl+Shift+Z`)

### 📅 Session Resume (세션 이어가기)
* **어떤 기능인가요?** 어제 하다가 멈춘 작업, 오늘 이어서 할 때 "내가 어디까지 했더라?" 하고 헤맬 필요가 없습니다. 이전 작업의 요약, 수정한 파일, 남은 작업 목록을 보여줍니다.
* **작동 원리:** VibeZoo가 이전에 AI와 작업했던 내용(주요 결정 사항, 남은 할 일 등)을 추적하여 로컬 메모리(Crow Memory)에 저장해두고, 다음 실행 시 사이드바의 트리(Tree) 구조로 예쁘게 파싱해서 보여줍니다.
* **사용 방법:** 사이드바의 **Session Resume** 탭을 펼쳐서 `📋 요약`, `📌 주요 결정`, `📄 수정 파일`, `⏳ 미완료 작업`을 확인하며 바로 업무에 돌입하세요. (단축키: `Ctrl+Shift+R`)

---

## 4. 요약

VibeZoo는 당신의 코드를 묵묵히 백업하고(YOLO), 위험한 수정으로부터 보호하며(FileGuard), 발생한 에러를 몰래 고쳐주는(Fix Loop) 든든한 **데이터센터의 천재 비서**입니다. 사용자는 단순히 코딩과 구조 설계에만 집중하시면 됩니다. 복잡한 뒤처리는 VibeZoo가 책임집니다.
